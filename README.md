# Стоп-кадр

Короткие истории для подростков о границах, групповом давлении и помощи человеку рядом. В каталоге 16 ситуаций, у каждой две роли. В четырёх медицинских историях можно играть за очевидца или за человека, которому стало плохо.

[Открыть игру](https://tchk-project.github.io/stop-kadr/docs/)

Кнопка «Играть» на главной сразу открывает случайную историю за одного из двух героев. В примере можно сменить ответ Дани. Из переписки и разбора кнопка «Следующая история» открывает другую историю в той же роли. На время вычитки ссылки с пометкой «(для проверяющих)» ведут в список всех 16 ситуаций. Из списка можно открыть конкретную историю в любой из двух ролей.

При первом входе в историю спокойный вариант выпадает с вероятностью 10%. В его финале можно запустить вариант с давлением. Каждая история начинается с жёлтого. На кнопке заранее видны выбранный уровень внимания и действие. При одной и той же внешней реакции можно по-разному прочитать ситуацию. Следующий сигнал позволяет сохранить, повысить или снизить уровень. В финале доступна история этих решений. После версии с давлением перемотка возвращает к видимым сигналам и выбранному ответу. Остановки можно листать и пробовать другой ответ с выбранной развилки. Скорость перемотки 4×. «Показать сразу» и системная настройка уменьшенного движения пропускают анимацию. Голосовые и видео включаются вручную.

При первом входе игрок узнаёт, почему удобно сохранять жёлтый фоном. Первую видимую подсказку для каждого из трёх остальных цветов браузер запоминает на устройстве. В шапке игры и в каталоге есть «Подробнее о цветах Купера».

## Запуск и публикация

Для локального запуска откройте `docs/index.html`. Pages может публиковать корень ветки `main` или её каталог `docs`. Прямая ссылка на любую роль имеет вид `docs/focus.html?case=locker&role=self`. Адрес `docs/focus.html` открывает «Сбор после уроков» за Мишу.

## Редактирование

У каждой истории своя папка в [stories](stories). В ней лежат каталоговая карточка, обе роли, реплики, развилки и детали для разбора. [Инструкция для автора](stories/README.md) показывает, как изменить текст и как добавить историю.

- `python scripts/build_stories.py` проверяет сценарии и собирает каталог и отдельный файл каждой истории в `docs/game/`. Установить зависимость можно командой `python -m pip install -r scripts/requirements.txt`.
- `docs/engine.js` отвечает за маршруты, историю выборов, уровни и разбор. Проигрыватель в `docs/scene.js` и `docs/attention-player.js` отвечает за сообщения, чаты, звук и перемотку.
- Перед публикацией запустите `python scripts/build_stories.py --check`, `python -m unittest discover -s tests -p "test_*.py"` и `node --test tests/*.test.cjs`. Для прогона через интерфейс откройте `tests/browser.html` на локальном веб-сервере и нажмите кнопку запуска.
- Вложения хранятся в `docs/assets/`. В сценах используются вымышленный скриншот, учебные слайды, нарисованный стикер, иллюстрированный клип с оригинальной мелодией и синтез речи Piper (Irina и Ruslan). У голосовых есть текст. Игровые реплики одинаково звучат в обеих точках зрения. У Миши, Лёши, Дани и Саши свои настройки голоса. Воспроизведение включается вручную.
- [Паспорт персонажей и вопросы для чтения со школьниками](editorial/characters.md) закрепляет роли, аватары и поведение героев. Проверка сценарных данных запускается командой `node --test tests/content.test.cjs`.
- `docs/assets/avatars.webp` — сгенерированный атлас вымышленных фотографий профилей.
