# Стоп-кадр

Короткие истории для подростков о границах, групповом давлении и помощи человеку рядом. В каталоге 16 ситуаций, у каждой две роли. В четырёх медицинских историях можно играть за очевидца или за человека, которому стало плохо.

[Открыть игру](https://tchk-project.github.io/stop-kadr/docs/)

Кнопка «Играть» на главной сразу открывает случайную историю за одного из двух героев. В примере можно сменить ответ Дани. Из переписки и разбора кнопка «Следующая история» открывает другую историю в той же роли. Ссылка «Выбрать историю» ведёт в каталог всех 16 ситуаций. Во время показа доступна кнопка «Пропустить историю». В каталоге можно выбрать любую из двух ролей.

При первом входе в историю спокойный вариант выпадает с вероятностью 10%. В его финале можно запустить вариант с давлением. Каждая история начинается с жёлтого. На кнопке заранее видны выбранный уровень внимания и действие. При одной и той же внешней реакции можно по-разному прочитать ситуацию. Следующий сигнал позволяет сохранить, повысить или снизить уровень. В финале доступна история этих решений. После версии с давлением перемотка возвращает к видимым сигналам и выбранному ответу. Остановки можно листать и пробовать другой ответ с выбранной развилки. Скорость перемотки 3×. «Показать сразу» и системная настройка уменьшенного движения пропускают анимацию. Голосовые и видео включаются вручную.

При первом входе под именем героя появляется краткая подсказка о жёлтом. Пояснения к цветам ответов можно раскрыть под вариантами. Из игры и каталога открывается памятка «Цвета в игре», из неё — полный исходный текст о цветах Купера.

## Запуск и публикация

Для локального запуска откройте `docs/index.html`. Pages может публиковать корень ветки `main` или её каталог `docs`. Прямая ссылка на любую роль имеет вид `docs/focus.html?case=locker&role=self`. Адрес `docs/focus.html` открывает «Сбор после уроков» за Мишу.

## Редактирование

[Открыть редактор историй](https://tchk-project.github.io/stop-kadr/docs/editor.html). Выбери историю или нажми «Написать историю». Сохранённые правки и отметки вычитки остаются в этом браузере. «Проверить в игре» проигрывает черновик. Для передачи другому человеку нажми «Скачать для передачи». Получатель может открыть файл в редакторе и продолжить работу.

Для ручного выпуска сопровождающий сверяет файл с актуальной копией проекта командой `python scripts/prepare_draft.py draft.json`. Она проверяет исходную версию, обе роли и вложения и печатает изменения. Параметр `--export ../reviewed-story` складывает проверенные YAML и медиа в новую папку за пределами проекта. Перенос и публикация выполняются отдельно после согласования.

[Читать сценарий в двух ролях](https://tchk-project.github.io/stop-kadr/docs/read-story.html?case=money). От каждого варианта можно перейти к последствиям и посмотреть, какие сигналы герой уже видел. Для локального чтения откройте `docs/read-story.html`.

У каждой истории своя папка в [stories](stories). В ней лежат каталоговая карточка, обе роли, реплики, развилки и детали для разбора. [Инструкция для автора](stories/README.md) показывает, как изменить текст и как добавить историю.

- `python scripts/build_stories.py` проверяет сценарии и собирает каталог и отдельный файл каждой истории в `docs/game/`. Установить зависимость можно командой `python -m pip install -r scripts/requirements.txt`.
- `docs/engine.js` отвечает за маршруты, историю выборов, уровни и разбор. Проигрыватель в `docs/scene.js` и `docs/attention-player.js` отвечает за сообщения, чаты, звук и перемотку.
- Перед публикацией запустите `python scripts/build_stories.py --check`, `python -m unittest discover -s tests -p "test_*.py"` и `node --test tests/*.test.cjs`. Браузерные тесты с установленным Playwright Chromium запускаются командой `python -m unittest discover -s tests -p "browser_*.py" -v`. Для прогона через интерфейс откройте `tests/browser.html` на локальном веб-сервере и нажмите кнопку запуска.
- Вложения хранятся в `docs/assets/`. В сценах используются вымышленный скриншот, учебные слайды, нарисованный стикер, иллюстрированный клип с оригинальной мелодией и восемь синтезированных голосовых. Лера, Миша и Даня озвучены с помощью [TeraTTSv2 от TeraSpace](https://huggingface.co/TeraSpace/TeraTTSv2), Лёша и Саша — с помощью [Silero TTS](https://github.com/snakers4/silero-models). У каждого героя свой голос. В обеих точках зрения звучит одна и та же запись с доступной расшифровкой. Воспроизведение включается вручную.
- [Паспорт персонажей и вопросы для чтения со школьниками](editorial/characters.md) закрепляет роли, аватары и поведение героев. Проверка сценарных данных запускается командой `node --test tests/content.test.cjs`.
- `docs/assets/avatars.webp` — сгенерированный атлас вымышленных фотографий профилей.
