# Стоп-кадр

Короткие интерактивные истории для обсуждения травли и группового давления. В первом эпизоде «Дубль для своих» участник читает чат школьной музыкальной группы, сравнивает два ответа на просьбу и выбирает, как поддержать собеседника.

Доступны две точки зрения — «Я очевидец» и «Давят на меня». Во второй роли публикацию записи обсуждают с тобой.

## Как запустить

Откройте `docs/index.html` в браузере. Для работы достаточно файлов из папки `docs`.

## Где вносить изменения

- `docs/self.html` — сцена от первого лица.
- `docs/index.html` — реплики, варианты ответа, пояснения и переходы между сценами.
- `docs/scene.css` — оформление истории и кнопок.
- `docs/scene.js` — развилки, перемотка переписки и завершение сцены.

Для публикации через GitHub Pages источником служит папка `/docs` ветки `main`.
