# Как написать историю

Открой [сценарий для чтения](https://tchk-project.github.io/stop-kadr/docs/read-story.html?case=money). Выбери историю и роль. По каждой кнопке можно перейти к следующей сцене, проверить реплики и вернуться к развилке. Лист строится из тех же данных, что и игра.

Скопируй папку похожей истории. Для переписки с голосовым подойдёт `sticker`, для медицинской истории — `speech`. Дай папке новое имя из строчных латинских букв, цифр и дефисов. Укажи то же имя в поле `id`.

| Файл | Что в нём менять |
|---|---|
| `story.yaml` | Название, место, герои, вводные для двух ролей, чаты и ссылка на памятку. `order` задаёт порядок карточек и необязателен. |
| `messages.yaml` | Реплики, медиа, реакции и подписи. Одну реплику могут видеть оба героя. Каждый маршрут перечисляет доступные ему реплики. |
| `witness.yaml`, `self.yaml` | Порядок реплик, развилки, финалы и разбор для каждой роли. |
| `media/` | Голосовые, изображения, видео и документы этой истории. Общие файлы можно брать из `./assets/`. |

В реплике укажи `speaker` и `text` или `media`. Поле `channel` переключает место разговора. Последующие реплики продолжаются там же до следующего переключения. Для очной сцены задай канал с `kind: scene` и пустым названием. Для чатов есть `private`, `group` и `voice`. Поле `caption` у реплики подходит для подписи времени или места.

У видео можно указать `description` с описанием кадра и звука и `captions` с путём к файлу WebVTT. Для презентаций поле `html` ведёт к текстовой версии с таблицами данных.

Например, здесь можно менять слова внутри двойных скобок. Именно их игрок увидит выделенными в разборе.

```yaml
lera-reminder:
  speaker: Лера
  channel: private-lera
  text: 'Я ему [[вчера написала]], чтобы перестал.'
```

В файле роли добавь `lera-reminder` в `messages` нужной сцены, например `pressure`. В словаре `cues` укажи пояснение под ключом `pressure/lera-reminder`. В поле `review.signals` последующего решения укажи тот же ключ. При добавлении реплик выше или ниже эти ссылки сохраняются.

Каждая роль начинается в `start`, с переходами в `calm` и `pressure`. В `choices` ключ — имя следующей сцены, значение — подпись кнопки. Обычная развилка содержит `question`. Финал содержит `outcome` из двух значений (тип и заголовок) и `note` с объяснением. Возможные типы исхода — `positive`, `negative`, `mixed`, `open`. У каждой сцены после старта один вход. Благодаря этому прямая ссылка на неё восстанавливает переписку. Сохраняй имена уже опубликованных сцен при правке текста.

Уровень сцены задаётся в `mode`. Для непроизвольной реакции укажи `reaction.from` и `reaction.through` — имена первой и последней реплик интервала и `summary` — пояснение. Для примера см. [личный маршрут истории у лестницы](stairs/self.yaml).

Из корня репозитория один раз установи зависимость сборки, затем пересобери сайт и запусти проверки.

```sh
python -m pip install -r scripts/requirements.txt
python scripts/build_stories.py
python scripts/build_stories.py --check
node --test tests/*.test.cjs
```

Открой `docs/index.html` или адрес нужной роли вида `docs/focus.html?case=sticker&role=self#pressure`. Для публикации включи в коммит папку источников и обновлённые файлы из `docs/game/`. Каталог создаётся при сборке автоматически.
